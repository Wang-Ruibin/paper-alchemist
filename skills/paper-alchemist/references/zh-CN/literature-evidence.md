# 文献发现与引用证据

[English](../literature-evidence.md)

## 从用户已有文献开始

先读用户的文献表、笔记及可访问论文。区分用于写作风格的论文与已授权支持当前论述的来源；蒸馏不自动把引用加入研究事实。查找文献不授权修改现有文风画像，用户要求更新时再走增量流程。

文献任务先明确问题和重要范围，复用已有来源，只检索缺口。优先使用原始出版物、官方仓库和出版方记录。可用时使用宿主检索工具，本地脚本不查询文献服务。只发送发现文献所需检索词，不发送私人稿件或结果表。

## 区分发现与核实

对相关来源分别记录以下观察：

1. 已发现：有检索结果或文献条目。
2. 已核对元数据：题目、作者、年份、标识符及版本与权威记录一致；预印本与正式发表版本分开。
3. 已检查内容：实际阅读了相关段落、表或公式。
4. 已判断支持关系：这些内容在所述范围内支持、反驳或不足以支持某项拟写论断。

DOI 能打开或题目熟悉不等于核实正文。无法获取的论文保持未读状态；只能读取摘要时，只使用摘要实际表达的内容，并记录阅读范围。不凭模型记忆补齐作者、日期、DOI、结果或引文。发现相关更正或撤稿通知时，将其与原来源一并保留，重新判断受影响论断；未执行检查不得声称已对所有来源筛查通知。

## 建立有用的证据矩阵

矩阵简明列出引用键、已核实身份/版本、研究或问题设置、方法、发现、相关局限、阅读范围及来源位置，再加入拟写论断和支持判断。保留精确单位、总体、目标方向及实验条件。采用短证据引文或绑定来源的笔记，不复制论文正文。

核对来源是否支持被引的整个分句。介绍某方法的论文不一定记录用户实现的配置，应拆开这些陈述。综合时保留冲突结果。相关关系不能支持因果论断，观察到的最好值不等于最优证书，窄范围比较不支持普遍优越性。说明哪些证据会改变解释，不在证据不足时强化期望结论。

检查现有稿件引用时，逐项列出被引分句及其键，核对来源身份并阅读支持位置，再具体定位未支持、误归因、含糊或未读的条目。建议的新文献只有在核实并加入用户允许文献表后才可引用，不悄悄插入。

## 让检索与请求的综述类型匹配

聚焦的叙述综述可保留有范围的检索记录：检索词、数据库或工具、日期、范围及重要覆盖缺口。新颖性陈述只能反映实际检索范围；零结果不能证明从未有人研究。按机制、假设或证据组织综合，不逐篇堆段落。

只有任务包含明确方案且实际执行时才称系统综述。记录纳入/排除标准、检索来源和日期、去重规则、带理由的研究级筛选决定、无法取得的全文及各步数量。区分重复记录与排除研究，让筛查、排除和纳入数量可对账。独立筛选只有在授权且实际可用时采用；同一 Agent 连读两次不是两名盲筛者。不能从随意检索编造 PRISMA 合规或数量。无法完成范围或覆盖时，交付边界明确的综合并指出剩余工作。

## 把证据交给写作流程

只把已核实、已授权的来源论断和引用键加入研究事实。未解决来源保留在研究笔记，不进入正文。需要持久审计时，按 [research-workflow.md](research-workflow.md) 记录实际检查过的来源文本、位置及稿件片段。本地检查器可发现文件过期和绑定断裂，来源是否蕴含该句仍由 Agent 判断。
